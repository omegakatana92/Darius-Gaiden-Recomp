# Darius Gaiden — Native Recompilation

Darius Gaiden Native Recomp is a fan-developed native port of Taito's 1994 arcade shoot-'em-up, bringing the classic horizontal-scrolling shooter to modern Windows, Linux, and Steam Deck systems.

The project aims to preserve the original arcade gameplay, graphics, sound, and performance while introducing modern features and quality-of-life improvements.

## Planned Features and Capabilities

- **Dual Edition Support:** Play the original Darius Gaiden or Darius Gaiden Extra Edition, with an option to switch between versions.
- **Native Execution:** Recompiled game code designed to run on modern PC hardware.
- **Save States:** Save and restore gameplay progress.
- **Modern Frontend:** Game selection, configuration menus, and customizable settings.
- **Controller Support:** Keyboard and gamepad input with configurable controls.
- **Display Options:** Aspect-ratio preservation, scaling, and fullscreen support.
- **Audio Support:** Preservation of the original arcade soundtrack and sound effects.
- **Cross-Platform Builds:** Targeting Windows x64, Linux x86-64, and Steam Deck.

## Supported Game Editions

1. Darius Gaiden (Original Arcade Version)
2. Darius Gaiden Extra Edition
